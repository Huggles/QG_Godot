**Quartermaster General WW2 — v0.9.4.0** (beta)

**New**
- Lost connections no longer end the game
  - The game pauses when a player stops responding, and everyone sees "Waiting for Bob to reconnect..." with a countdown
  - While paused, the board, hand and prompts are greyed out; the camera, chat and menus still work
  - After 30 seconds the host chooses: keep waiting, save & quit, or let a bot take over that player's factions
- Rejoining a running game
  - A player who dropped out can join again by IP or from the Steam friends list and goes straight back to their own seat
  - The game pauses while they catch up, then shows them any prompt that was waiting on them
  - If a bot had taken over, the player gets their factions back
  - Anyone else trying to join is told the game is already in progress
- Players panel in the top-left (toggle it in the mini menu) showing each player's ping and connection status
- Leave button in the multiplayer lobby

**Changed**
- Host Game dialog: Steam is the default, and IP hosting is now a small "instead" button
- The Steam friends list shows the host's game version, and joining a game on a different version is refused
- The lobby's Start and Invite buttons match the menu button style
