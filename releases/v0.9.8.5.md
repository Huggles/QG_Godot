**Quartermaster General WW2 — v0.9.8.5** (beta)

**New**
- Loading a skirmish save now takes you straight back into the game against the AI, with the same difficulty and bot seats; online and ranked saves still go through the lobby
- The load list shows whether each save is a Skirmish, Online or Ranked game

**Changed**
- Quit to Menu now warns you if a save is still waiting to be written, and the save notice tells you to stay in the game until it's done
- Standard Game now starts with the opening discard, with or without Total War
- The lobby no longer offers the opening-discard toggle; games use the scenario or save setting

**Fixed**
- Flexible Resources now asks you to pick exactly one card from your discard pile to play, and can no longer be skipped
