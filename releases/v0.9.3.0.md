**Quartermaster General WW2 — v0.9.3.0** (beta)

**New**
- In-game chat in the bottom-left
  - Global and Team channels: switch with the All/Team button or Tab while typing
  - Player and Game filter buttons
  - Pops up for new player messages, on hover, or when you press Enter to type
  - New setting Settings > Gameplay > "Hide Chat After": Never, 5 seconds (default) or 10 seconds

**Changed**
- Action banner messages
  - Name the faction they are about and read the same on every player's screen
  - Prompts start with the faction being asked, e.g. "Germany: Choose a card"
  - Long messages stay on one line and shrink to fit
  - Response and status card notes (RAF, Radar, Truk, Stalingrad and more) and the supply-loss note show for every player, not only the host
- HUD layout
  - The bottom-left menu moved to the top-left
  - The skip buttons sit, smaller, next to the chat
  - The additional cards fan is smaller and sits lower, beside your hand

**Fixed**
- Restoring saved games
  - Joining a restored online game no longer desyncs the client on bigger saves. The host sent the whole game history at once, and over Steam part of it got lost, so the joining player's game no longer matched the host's. The history is now sent in smaller, checked chunks
  - Loading a save no longer shows the prompt it was saved on a second time
- Playing Leningrad, Moscow or Stalingrad now names the country whose army was saved, instead of showing garbled text
